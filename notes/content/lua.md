## How to read this reference

A **chunk** is one packaged compiled Lua file: its top-level prototype can contain nested functions. A **resolved callback** is a level or marker placement linked to an entry point in a non-client chunk; the same callback can be placed more than once. A **called function** is a global or table member statically observed flowing into a Lua `CALL` or `TAILCALL`; one function can be called by many chunks with different arguments.

`direct` chunk links come from `level_script`; `dependency` links inherit usage through resolved `lua_dependency` edges. Indirect calls through closures or unresolved registers are not guessed. `server` authority requires an authored server-only marker or a proven server Lua resource group; `candidate` means the chunk is level-reachable but its execution authority is not yet recovered. Client groups `0xA35BED24` and `LuaClient`, plus calls into `nClient` and `nUIManager`, are omitted. Scopes are evidence labels computed only from the remaining graph.
